Freelance media technician from Austria: graphic design, web design, Laravel (TALL Stack), WordPress, MadStack and vector animation.

Here on GitHub I build [Home Assistant](https://www.home-assistant.io/) integrations for Austrian public data, plus a few Lovelace cards. Everything installs through the [Marketplace](https://www.home-assistant.io/integrations/marketplace/) and speaks English and German.

[![Live demo](https://img.shields.io/badge/Live%20demo-b71643?style=flat-square)](https://demo.rolandzeiner.at)

## Home Assistant integrations

**Getting around**
- <a href="https://github.com/rolandzeiner/wiener-linien-austria"><img src="assets/icons/wiener-linien-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [wiener-linien-austria](https://github.com/rolandzeiner/wiener-linien-austria): live departures for Vienna's public transport
- <a href="https://github.com/rolandzeiner/linz-linien-austria"><img src="assets/icons/linz-linien-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [linz-linien-austria](https://github.com/rolandzeiner/linz-linien-austria): live departures for LINZ AG LINIEN
- <a href="https://github.com/rolandzeiner/nextbike-austria"><img src="assets/icons/nextbike-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [nextbike-austria](https://github.com/rolandzeiner/nextbike-austria): nextbike stations in Vienna, Lower Austria, Tyrol, Linz and Klagenfurt

**Fuel and charging**
- <a href="https://github.com/rolandzeiner/tankstellen-austria"><img src="assets/icons/tankstellen-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [tankstellen-austria](https://github.com/rolandzeiner/tankstellen-austria): fuel prices from E-Control's Spritpreisrechner
- <a href="https://github.com/rolandzeiner/ladestellen-austria"><img src="assets/icons/ladestellen-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [ladestellen-austria](https://github.com/rolandzeiner/ladestellen-austria): EV charging stations from E-Control's Ladestellenverzeichnis

**Environment**
- <a href="https://github.com/rolandzeiner/badegewaesser-austria"><img src="assets/icons/badegewaesser-austria.png" width="20" height="20" alt="" align="absmiddle"></a> [badegewaesser-austria](https://github.com/rolandzeiner/badegewaesser-austria): water quality at Austria's 260 official bathing sites (AGES)
